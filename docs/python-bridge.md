# 🐍 Universal Python Polyglot Bridge

One of the greatest hurdles for any new programming language is the **20-year library cold-start problem**. Without PyTorch, NumPy, Pandas, Scikit-learn, and Hugging Face, scientific developers cannot migrate.

EraLang solves this permanently via the **Universal Polyglot Bridge** (`eralang/bridge_python.py`).

---

## 🚀 How to Import Python Packages

Simply prefix the package import with `python:`:

```rust
// example: importing Python packages in EraLang
import python:math as py_math
import python:json as py_json

let val = py_math.sin(1.57079)
print("Sine from Python math: " + to_str(val))
```

---

## 🧠 Using PyTorch or NumPy in EraLang

```rust
import python:numpy as np

let arr = np.array([10.0, 20.0, 30.0, 40.0])
let mean = np.mean(arr)
let std = np.std(arr)

print("NumPy Mean: " + to_str(mean))
print("NumPy Std : " + to_str(std))
```

## 🛡️ Sandbox Mode for Untrusted Code

When running code generated by AI models, you can run in sandbox mode to restrict dangerous system and network calls:

```bash
era run script.era --sandbox
```
